# Backwards-compatible alias for rena_plus

Backwards-compatible alias for rena_plus

## Usage

``` r
er_ml_rena(bvec, mask, ...)
```

## Arguments

- bvec:

  A `NeuroVec` providing voxel time-series.

- mask:

  A `NeuroVol` mask; finite positive voxels are included.

- ...:

  Reserved for future options.

## Value

Same as
[`rena_plus`](https://bbuchsbaum.github.io/neurocluster/reference/rena_plus.md).
